# testflow meow meow

An open-source extension for Testportal, Wayground, and Quizizz. Runs locally, with no server or license key.

Designed for Quetta on Android and Orion on iOS. Mobile compatibility is still being tested.

## Install

1. Download the extension ZIP from [Releases](https://github.com/ciagnij/testflow-meow-meow/releases).
2. On your phone, open the browser's **Extensions** menu and install it from a file. In Orion, enable Chrome extensions in Settings first.
3. Allow access to the supported websites, then reload the page.

On desktop, extract the ZIP and use **Developer mode → Load unpacked** at `chrome://extensions` or `edge://extensions`.

Enable or disable the extension from its popup, then reload the page.
