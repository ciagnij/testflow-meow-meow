# testflow meow meow

An open-source extension for Testportal, Wayground, and Quizizz. Runs locally, with no server or license key.

## Install

1. Download this repository as a ZIP and extract it.
2. Open `chrome://extensions` or `edge://extensions`.
3. Enable **Developer mode**.
4. Click **Load unpacked** and select the folder containing `manifest.json`.

Enable or disable the extension from its popup, then reload the page.
